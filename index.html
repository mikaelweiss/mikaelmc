How to join

Java Edition

  1. Open Multiplayer and click Add Server.
  2. Paste the Java address. No port needed.
  3. Click Done, then double-click the server to join.

Bedrock Edition on phone, tablet, or Windows

  1. Tap Play, open the Servers tab, and scroll to the bottom for Add Server.
  2. Paste the Bedrock address and type its port.
  3. Save, then tap the server to join.

Bedrock always runs the latest release. Xbox, PlayStation, and Switch hide the Add Server button. You can still get on. Ask me and I will show you how.

If a server is down, I broke it. Give it a minute.
