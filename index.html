How to join

Java Edition

  1. Multiplayer, then Add Server.
  2. Paste the Java address. Leave the port alone.
  3. Done, then double-click the server.

Bedrock Edition (phone, Windows, tablet)

  1. Play, then the Servers tab, then scroll down to Add Server.
  2. Paste the Bedrock address and type the port listed above.
  3. Save, then tap it to join.

Bedrock runs the latest release. On Xbox, PlayStation, or Switch it hides the Add Server button. It is still possible. Ask me.
